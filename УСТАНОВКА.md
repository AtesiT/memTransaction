# Что нужно для сборки и запуска

Короткая инструкция: что должно быть установлено на компьютере, чтобы открыть
и запустить приложение из папки `maui/`.

## Обязательно

| Компонент | Версия | Зачем |
|---|---|---|
| Windows | 10 (сборка 19041, версия 2004) или 11 | целевая платформа приложения |
| Visual Studio | 2022 (17.8+) или новее | среда разработки |
| Нагрузка VS **«.NET Multi-platform App UI development»** | — | даёт .NET MAUI и нагрузку `maui-windows` |
| .NET SDK | **10.0** (по умолчанию в проекте) | компилятор и платформа |

Язык — **C#**, отдельно ставить ничего не нужно: версия языка берётся от SDK
автоматически (C# 14 при .NET 10 SDK, C# 12 при .NET 8 SDK). XAML и .NET MAUI
приходят вместе с нагрузкой Visual Studio.

## Если стоит .NET 8 или 9 вместо 10

В файле `maui/TmLab/TmLab.csproj` поменяйте одну строку:

```xml
<DotNetVersion Condition="'$(DotNetVersion)' == ''">10.0</DotNetVersion>
```

на свою версию (`8.0` или `9.0`). Больше ничего править не нужно.
Проверить, что стоит: `dotnet --list-sdks`, список нагрузок — `dotnet workload list`
(должна быть строка `maui-windows`).

## Что НЕ нужно

- **Режим разработчика и сертификат подписи** — приложение собирается без упаковки
  в MSIX, как в новом шаблоне MAUI.
- **Windows App Runtime** — в unpackaged-режиме MAUI сама включает
  `WindowsAppSDKSelfContained`, среда кладётся рядом с программой.

## Запуск на Android (по желанию)

Для Windows-версии Android SDK не нужен: проект по умолчанию собирается только
под Windows (`WindowsOnly=true` в csproj). Если захотите запустить на телефоне
или эмуляторе, дополнительно понадобится:

- **Android SDK** — ставится вместе с нагрузкой
  «.NET Multi-platform App UI development» в Visual Studio;
- **эмулятор или телефон**: эмулятор запускается из Visual Studio
  (Tools → Android Emulator Manager) или Android Studio, телефон подключается
  кабелем с включённой отладкой по USB.

Запуск — файлом `maui/build-android.cmd`: он сам проверит подключённые
устройства, соберёт проект под Android, установит приложение и запустит его.
В Visual Studio для запуска на Android поставьте `WindowsOnly=false`
в `maui/TmLab/TmLab.csproj` и выберите устройство в списке.

## Как запустить

1. Открыть `maui/TmLab.sln` в Visual Studio.
2. В списке устройств выбрать **Windows Machine**, нажать **F5**.

Или из командной строки (только сборка, без запуска):

```bat
cd maui/TmLab
dotnet build
```

## Если что-то не работает

- Ошибка «You must install or update .NET to run this application» — в csproj
  указана версия .NET, которой на компьютере нет: поправьте `DotNetVersion`.
- Для диагностики есть `maui/build-windows.cmd` — он делает чистую сборку
  и пишет подробности в `maui/build-log.txt`.
- Подробности — в `maui/README.md`.
