# Что нужно для сборки и запуска

Короткая инструкция: что должно быть установлено на компьютере, чтобы открыть
и запустить приложение из папки `maui/`.

## Обязательно

| Компонент | Версия | Зачем |
|---|---|---|
| Windows | 10 (сборка 19041, версия 2004) или 11 | целевая платформа приложения |
| Visual Studio | 2022 (17.8+) или новее | среда разработки |
| Нагрузка VS **«.NET Multi-platform App UI development»** | — | даёт .NET MAUI и нагрузку `maui-windows` |
| .NET SDK | **10.0** (по умолчанию в проекте) | компилятор и платформа |

Язык — **C#**, отдельно ставить ничего не нужно: версия языка берётся от SDK
автоматически (C# 14 при .NET 10 SDK, C# 12 при .NET 8 SDK). XAML и .NET MAUI
приходят вместе с нагрузкой Visual Studio.

## Если стоит .NET 8 или 9 вместо 10

В файле `maui/TmLab/TmLab.csproj` поменяйте одну строку:

```xml
<DotNetVersion Condition="'$(DotNetVersion)' == ''">10.0</DotNetVersion>
```

на свою версию (`8.0` или `9.0`). Больше ничего править не нужно.
Проверить, что стоит: `dotnet --list-sdks`, список нагрузок — `dotnet workload list`
(должна быть строка `maui-windows`).

## Что НЕ нужно

- **Режим разработчика и сертификат подписи** — приложение собирается без упаковки
  в MSIX, как в новом шаблоне MAUI.
- **Windows App Runtime** — в unpackaged-режиме MAUI сама включает
  `WindowsAppSDKSelfContained`, среда кладётся рядом с программой.

## Запуск на Android (по желанию)

Для Windows-версии Android SDK не нужен: проект по умолчанию собирается только
под Windows (`WindowsOnly=true` в csproj). Если захотите запустить на телефоне
или эмуляторе, дополнительно понадобится:

- **Android SDK** — ставится вместе с нагрузкой
  «.NET Multi-platform App UI development» в Visual Studio. Если сборка
  падает с ошибкой `XA5300` («The Android SDK directory could not be found») —
  значит, SDK не встал: откройте Visual Studio Installer → Modify и убедитесь,
  что нагрузка установлена (или поставьте Android Studio / командные инструменты
  вручную и задайте переменную `ANDROID_HOME` на папку SDK);
- **эмулятор или телефон**: эмулятор запускается из Visual Studio
  (Tools → Android Emulator Manager) или Android Studio, телефон подключается
  кабелем с включённой отладкой по USB.

Запуск — файлом `maui/build-android.cmd`: он сам проверит подключённые
устройства, соберёт проект под Android, установит приложение и запустит его.
А файл `maui/build-android-apk.cmd` только собирает APK
(`maui/TmLab/bin/Debug/net10.0-android/TmLab.apk`) — его можно скинуть
на телефон и установить вручную. В Visual Studio для запуска на Android
поставьте `WindowsOnly=false` в `maui/TmLab/TmLab.csproj` и выберите
устройство в списке.

### SDK на другом диске (например, D:)

Visual Studio ставит SDK в `%LOCALAPPDATA%\Android\Sdk` (диск C:). Чтобы SDK
лежал на D:, проще всего поставить **Android Studio** и в мастере установки
указать путь SDK `D:\Android\Sdk` — он сам скачает platform-tools, платформу
и build-tools. После установки проверьте переменную окружения `ANDROID_HOME`
(должна указывать на `D:\Android\Sdk`; если её нет — создайте через
Win+R → `sysdm.cpl` → Дополнительно → Переменные среды). Скрипты сборки ищут
SDK по `ANDROID_HOME` и по стандартному пути, поэтому после этого всё работает
как обычно. Эмулятор для APK не нужен; для запуска на устройстве
(`build-android.cmd`) создайте его в Android Studio (AVD Manager) или
подключите телефон с отладкой по USB.

### Ручная установка SDK (командные инструменты)

Если Android Studio ставить не хочется:

1. Скачайте **command-line tools**: https://developer.android.com/studio#command-line-tools-only
2. Распакуйте так, чтобы получилось `D:\Android\Sdk\cmdline-tools\latest\bin\sdkmanager.bat`
   (в архиве лежит папка `cmdline-tools` — переименуйте её в `latest` и положите
   в `D:\Android\Sdk\cmdline-tools\`).
3. `sdkmanager` нужен Java. Поставьте **Microsoft OpenJDK 21**:
   https://learn.microsoft.com/en-us/java/openjdk/download — раздел JDK 21,
   Windows, x64, файл `.msi`. Установщик сам пропишет переменную `JAVA_HOME`
   (обычно `C:\Program Files\Microsoft\jdk-21.0.x-hotspot`).
4. Откройте **новое** окно командной строки (старое переменные не увидит)
   и проверьте: `java -version` и `echo %JAVA_HOME%`. Если `JAVA_HOME` пустая —
   пропишите вручную: Win+R → `sysdm.cpl` → Дополнительно → Переменные среды →
   в «Системных переменных» создайте `JAVA_HOME` со значением папки JDK
   (та, где лежит `bin\java.exe`).
5. Установите пакеты и примите лицензии:
   `D:\Android\Sdk\cmdline-tools\latest\bin\sdkmanager.bat --install "platform-tools" "platforms;android-36" "build-tools;36.0.0"`,
   затем `... --licenses` (несколько раз нажать `y`).
6. Задайте `ANDROID_HOME=D:\Android\Sdk` (как в пункте 4) и запустите
   `build-android-apk.cmd`.

## Как запустить

1. Открыть `maui/TmLab.sln` в Visual Studio.
2. В списке устройств выбрать **Windows Machine**, нажать **F5**.

Или из командной строки (только сборка, без запуска):

```bat
cd maui/TmLab
dotnet build
```

## Если что-то не работает

- Ошибка «You must install or update .NET to run this application» — в csproj
  указана версия .NET, которой на компьютере нет: поправьте `DotNetVersion`.
- Для диагностики есть `maui/build-windows.cmd` — он делает чистую сборку
  и пишет подробности в `maui/build-log.txt`.
- Подробности — в `maui/README.md`.
